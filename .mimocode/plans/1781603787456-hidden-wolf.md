# Orbital Overview Preset 实现计划

## 目标
创建 `OrbitalOverview` preset，复刻参考图中的轨道概览 UI 面板，包含动画行星轨道。

## 确认参数
- 面板尺寸：520×400（横向）
- 动画风格：匀速公转

## 核心实现

### 面板
- 520×400 viewBox
- 深色玻璃背景 + 发光边框 + 角标

### 轨道系统（左侧区域）
- 5 条椭圆轨道，rx 从 50→200，ry 从 25→100（透视压缩比 0.5）
- 椭圆中心偏左：cx≈190, cy≈200

### 中心恒星
- 位置：轨道中心
- 径向渐变 + feGaussianBlur 发光
- 脉冲动画：opacity 0.7→1.0

### 行星（6个）
- 分布在不同轨道，不同起始角度
- 公转动画：`angle = startAngle + progress * speed * 360°`
- 位置：`x = cx + rx * cos(angle)`, `y = cy + ry * sin(angle)`

### 轨道拖尾
- 选中 2 条轨道添加发光渐变效果

### 右侧信息栏
- 标签：STAR / PLANETS / MOONS / WAYPOINTS / DISTANCE
- 值：KELVAR-7 / 5 / 12 / 3 / 2.4 AU
